# ml/ — ข้อมูลเทรนและการเทรนโมเดล

เจ้าของ: Chalakorn (C2, C4, C6)

- `templates/` แม่แบบสร้างข้อมูลเทรน — **Wissarut ห้ามเปิด** เพื่อให้ชุดทดสอบเขียนด้วยมือไม่ตรงกับข้อมูลเทรน
- `data/` ข้อมูลเทรนที่สร้างแล้ว — ไม่ขึ้น git
- ไฟล์โมเดลไม่ขึ้น git ให้อัปโหลดไว้ที่ GitHub Release / HF private / Drive แล้วใส่ลิงก์ใน `docs/MODEL_CARD.md`
- **ห้ามใช้ข้อมูลใน `eval/sets/` มาเทรน** ปรับข้อมูลจากข้อผิดของ val / unseen ได้เท่านั้น (C4)
