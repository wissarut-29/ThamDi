# schema ที่ใช้ทดสอบ

ส่งให้ Chalakorn ภายใน 3 พ.ย. 12:00 (จุดส่งของใน `docs/TASKS.md`)

| schema | ตาราง | โมเดลเห็นตอนเทรน? | ข้อใน handwritten |
|---|---|---|---|
| `sales` | `customers`, `products`, `orders`, `order_items` | ✅ เห็น | 35 (h001–h035) |
| `clinic` | `patients`, `doctors`, `appointments` | ❌ **ห้ามใช้เทรน** | 21 |
| `library` | `members`, `books`, `loans` | ❌ **ห้ามใช้เทรน** | 14 |

## สิ่งที่ Chalakorn ต้องทำ

1. **`sales`** — ตาราง/คอลัมน์ใน `sales.sql` ต้องตรงกับฐานข้อมูลที่ `scripts/gen_sales_db.py` สร้างและใช้เทรน ถ้าของจริงต่างไป แจ้ง Wissarut เพื่อแก้ SQL เฉลยให้ตรง (ข้อมูลแถวไม่ต้องตรง เพราะ eval ใช้ข้อมูลในไฟล์นี้)
2. **`clinic`, `library`** — ห้ามมีในข้อมูลเทรน รวมถึง schema ที่คล้ายกันมาก (โรงพยาบาล/คลินิก/นัดหมาย, ห้องสมุด/ยืม-คืน) เพื่อให้ผล unseen เชื่อถือได้

ไฟล์ `.sql` แต่ละไฟล์แบ่งเป็น 2 ส่วนด้วยบรรทัด `-- data`: ส่วนบนเป็น DDL ที่ส่งให้โมเดล ส่วนล่างเป็นข้อมูลตัวอย่างสำหรับรัน SQL
